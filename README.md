# 刘洛学术主页

This repository contains a static bilingual academic homepage for Liu Luo. It can be deployed directly with GitHub Pages.

## Update Content

- Update `index.html` for biography, publications, projects, academic service, and contact details.
- The profile image is stored at `assets/liuluo-profile.jpeg`.
- Publication records are stored in `publications.js` and rendered by `site.js`; the default language is English, with a Chinese switch in the header.

## Deploy on GitHub Pages

1. Push these files to a repository named `USERNAME.github.io`.
2. In GitHub, open **Settings -> Pages**.
3. Set the source to the `main` branch and root directory.
4. Visit `https://USERNAME.github.io/` after GitHub finishes publishing.
